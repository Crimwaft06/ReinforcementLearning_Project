# ReinforcementLearning_Project

A reinforcement learning project to simulate and analyze traffic light control.

## Project structure

```text
ReinforcementLearning_Project/
├── README.md
├── ReinforcementLearning.py
├── requirements.txt
├── .gitignore
├── data/
├── notebooks/
├── src/
├── results/
└── .venv/
```

## Requirements

- Python 3.9+
- Recommended virtual environment

## Initial setup

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the project

```bash
python ReinforcementLearning.py
```

## Main dependencies

- numpy
- pandas
- matplotlib
- seaborn
- scikit-learn
- jupyterlab
- tqdm
- gym

## Notes

- The `src/` folder is reserved for larger modules and logic.
- `data/` is used for input files and datasets.
- `notebooks/` is useful for experiments, analysis, and visualizations.
- `results/` stores graphs and experiment output.
